- 2026-09-28 moving-car shadows: with r.ray_traced_shadows 1 the sun shadow of the driving car trailed and faded with speed (ground and car body) while raster shadow maps (r.ray_traced_shadows 0) stayed correct. Root cause was a cpu/gpu race: the renderer runs 4 frames in flight (renderer_draw_data_buffer_count) but RHI_AccelerationStructure::buffer_count was 2, so tlas instance staging got overwritten with a later frame's car transform before the gpu built it. Now 4. The bug is invisible in screenshot_take because FinalizeScreenshotReadback calls QueueWaitAll (drains the gpu), so "a screenshot fixes it" = frames-in-flight race; verify such bugs by asking the user to drive, not with captures. Also set NRD SIGMA maxStabilizedFrameNum 0 (it trails moving occluders' shadows). Remaining same-class race: the GeometryInfo storage buffer is rewritten at offset 0 each tlas rebuild while older frames may read it (affects rt hit shading, not opaque shadow rays). A/B shadow bugs by toggling r.ray_traced_shadows first.
